# EstateHub — downloads

Installers and the automatic-update feed for **EstateHub**, the local-first real estate manager
(rentals, sales, short stays, income & expense, ledger, receipts). Your business data stays on your computer.

## Download

| System | File |
| --- | --- |
| Windows 10 / 11 (64-bit) | [EstateHub-Setup.exe — latest](https://github.com/mashahwani/estatehub-releases/releases/latest) |
| Linux (any distro) | `EstateHub-<version>.AppImage` on the [latest release](https://github.com/mashahwani/estatehub-releases/releases/latest) |
| Debian / Ubuntu | `EstateHub-<version>.deb` (does not update itself; install new versions by hand) |

All versions: [Releases](https://github.com/mashahwani/estatehub-releases/releases).

## Updates

You only install once. EstateHub checks this page for a new version in the background (a few KB) and **never
downloads anything until you choose to**:

1. A notification says *"EstateHub x.y.z is available"* and shows the download size.
2. Click **Update** in the title bar (or Settings → App updates). Only the **changed parts** of the app are
   downloaded, usually a few MB, not the whole installer.
3. Click **Restart to update**. Your data is not touched.

Every update is signed by EstateHub; the app refuses anything that is not.

## Activation

EstateHub needs a licence key from your vendor. A 14-day trial is available on first start.
